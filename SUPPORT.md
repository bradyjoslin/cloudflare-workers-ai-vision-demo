# Support

This is a personal demo/starter project and is not an official Cloudflare product or support channel.

## Questions

- Start with the [README](README.md), especially the setup, deploy, and troubleshooting sections.
- For project-specific questions, open a GitHub issue.
- For Cloudflare platform questions, use the official documentation and community resources listed below.

## Bug Reports

Use the [Bug Report template](.github/ISSUE_TEMPLATE/bug_report.md). Include:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Browser and OS
- Whether you were running locally or on `workers.dev`
- Any relevant console or Worker logs, with secrets removed

## Feature Requests

Use the [Feature Request template](.github/ISSUE_TEMPLATE/feature_request.md). Explain the problem first, then the proposed solution.
